# R15.1 — Cap home-page prose at a reading measure

**Status:** planned
**Files:** `src/routes/home/AboutStarSection.tsx`, `src/routes/home/FAQSection.tsx`,
`src/routes/home/JoinUsSection.tsx`, `design/tokens.md` (amend layout note)

## Spec

**Problem:** home-page body copy has per-section horizontal padding (`px-5`–`px-20`)
but no max-width, so at desktop widths text lines run nearly the full viewport
(~1760–1830px at 1920px — verified via Playwright screenshots). Way past a readable
measure; the user flagged it. Card/graphic rows (stats, sponsors, e-board, projects,
globe) are fine — only continuous text is affected. Hero already caps at
`max-w-[600px]`.

**Approach:** purely additive Tailwind classes; parents are already
`flex flex-col items-center`, so a `max-w-*` on the text element centers naturally
(no `mx-auto` needed). Per `design/components.md` (centered column ≈ 3xl–5xl):

- `AboutStarSection.tsx` — add `max-w-3xl` to the four prose paragraphs: SEDS intro
  (`md:px-10`), mission statement (`mt-14 md:px-10`), "Why STAR?" body (`leading-8`),
  and the sponsors lead-in line.
- `FAQSection.tsx` — the accordion wrapper (`px-20` div) gets its `Accordion` capped
  with `max-w-4xl` (wider than plain prose since triggers + chevrons are row-like,
  but nowhere near full-bleed).
- `JoinUsSection.tsx` — add `max-w-3xl` to the Discord instructions paragraph.
- `design/tokens.md` — amend the "No fixed max-width grid" layout note: home prose is
  now capped (`max-w-3xl`, accordion `max-w-4xl`); sections themselves stay full-width.

No state, no data flow, no packages — class-only change.
