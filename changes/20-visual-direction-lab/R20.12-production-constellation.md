## Spec

**Problem:** The user selected the frameless Kinetic STAR Constellation for the homepage, but the
production hero still loads the rejected provisional CubeSat model. The selected prototype also
contains design-lab annotations that add visual noise without helping a homepage visitor.

**Approach:** Promote the constellation, shared project metadata, and visual-activity hook from the
design lab into reusable production modules. Replace the homepage `ExplodedCubeSat` lazy load and
placeholder delay with the lightweight canvas constellation. Remove all visible instrumentation
captions from the constellation while retaining its accessible canvas label. Drive its Robotics,
Weather Balloon, and CubeSat signal states from the existing project links on pointer hover and
keyboard focus; default to CubeSat when no link is previewed. Preserve the current hero copy, CTA,
layout, link destinations, navbar, and equal project sizing. The canvas starts on CubeSat, then
retains the most recently hovered or keyboard-focused project for the rest of the current page
load instead of snapping back when the pointer leaves. Keep the design-lab comparison working
through imports from the promoted modules. Do not delete the deferred CubeSat prototype source.

The existing global user/system motion preference controls the canvas. Its IntersectionObserver,
document-visibility pause, 30 fps limit, and 1.5 DPR limit remain unchanged. No package changes are
required.
