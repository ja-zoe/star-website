# R20.5 — Rutgers-facing paused globe

**Status:** planned
**Files:** `src/components/magicui/globe.tsx`

## Spec

**Problem:** Turning motion off destroys the COBE instance after its first frame. Because WebGL does
not preserve that drawing buffer, the globe disappears instead of becoming a useful static visual.

**Approach:** Keep the COBE instance mounted while motion is reduced and stop incrementing its rotation.
Reset to a deterministic paused rotation that keeps the New Brunswick marker in frame. Preserve the
existing offscreen/page-hidden lifecycle, pointer behavior when motion is enabled, and running-state data
attribute. The paused frame must remain visible for both the site control and system reduced motion.

- [ ] Resuming motion rotates from the visible globe; pausing again returns to the Rutgers-facing frame.
- [ ] System reduced motion renders the same static globe without console errors or overflow.
