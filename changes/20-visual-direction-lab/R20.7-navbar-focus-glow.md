# R20.7 — Navbar focus and open-state glow correction

**Status:** tests passing
**Files:** `src/App.css`

## Spec

**Problem:** The scroll-aware navbar's red active and hover styles coexist with the shadcn
NavigationMenu light-theme `focus:bg-accent` and `data-[state=open]:bg-accent` utilities. Clicking
a link can briefly flash white, and the Projects trigger can remain white while its menu is open.

**Approach:** Scope explicit focus, focus-visible, and Radix open-state overrides to
`data-scroll-aware-navigation`. Keep the same two-state language: persistent deep-red current
location and brighter coral hover/focus/open exploration. Do not change the user's navbar classes,
spacing, rounded controls, trigger geometry, or scroll-state calculation.

## Tests

- [x] `pnpm lint` and `pnpm build` pass.
- [x] Pointer-down, focus, focus-visible, and Projects open/close never compute a white background.
- [x] Current and separately hovered/open controls retain visibly different red glow values.
- [x] All five active sections, keyboard navigation, geometry, console, and overflow remain clean.
