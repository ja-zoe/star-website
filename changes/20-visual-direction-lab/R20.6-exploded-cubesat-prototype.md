# R20.6 — Interactive exploded CubeSat hero prototype

**Status:** planned
**Files:** `src/routes/home/HeroSection.tsx`, `src/components/hero/ExplodedCubeSat.tsx`, design records

## Spec

**Problem:** The hero has a strong editorial layout but lacks a distinctive hardware visual. The right
column is useful navigation, yet it does not immediately communicate the physical systems students build.

**Approach:** Add a stylized parametric CubeSat assembly above the existing equal-prominence program links
in the hero's right column. Build it with the existing React Three Fiber/Three.js stack and lazy-load its
chunk after the initial interface is usable. Model a central bus, frame, avionics/payload faces, antenna,
and paired solar arrays with restrained STAR-red hardware accents. Start in an exploded view; provide a
clear assemble/explode control and pointer-drag rotation. Allow slow idle rotation only when motion is
enabled. Reduced motion keeps a useful static exploded frame and all controls keyboard accessible. Keep
the existing CTA-left/projects-right composition and do not replace or reprioritize the three program links.
