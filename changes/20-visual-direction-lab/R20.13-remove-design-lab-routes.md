# R20.13 — Remove production design-lab routes

**Status:** done
**Files:** `src/App.tsx`

## Spec

**Problem:** The Set 20 branch still registers `/design-lab` and
`/design-lab/hero-visuals`. Although both routes are marked `noindex`, they would remain publicly
accessible after deployment and their prototype chunks would be shipped in `dist/`.

**Approach:** Remove both lazy imports and both route registrations from `App`. Retain the design-lab
source files and historical review artifacts in the repository, but leave them unreachable from the
production application graph. Both URLs must fall through to the existing wildcard `NotFound` route.
Do not change the selected production constellation or any public navigation.

- [x] `/` still renders the selected frameless constellation, persistent project states, and existing

- [x] The built `dist/` includes the Apache SPA fallback configuration.
