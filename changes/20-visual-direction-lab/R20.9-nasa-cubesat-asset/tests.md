# R20.9 future integration test scheme

- [ ] The supplied GLB validates and its source checksum is recorded.
- [ ] Mesh, material, texture, node, and animation-clip budgets are documented before integration.
- [ ] The authored assembled/exploded animation plays and reverses without client-authored geometry.
- [ ] Offscreen, hidden-page, and user/system reduced-motion behavior pause or eliminate animation.
- [ ] Desktop/mobile visual, interaction, overflow, and console checks pass.
- [ ] Repository lint and production build pass.
