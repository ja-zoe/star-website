# R18.3 — Reliable hash navigation

**Status:** done
**Files:** `src/App.tsx`, `src/components/Navbar.tsx`, `src/routes/home/AboutStarSection.tsx`, `src/routes/home/ProjectsSection.tsx`, `src/routes/home/FAQSection.tsx`, `src/routes/home/JoinUsSection.tsx`, `src/routes/home/EboardSection.tsx`

## Spec

**Problem:** Browser hash scrolling runs before the lazy home route mounts, so
cold hash links and project-to-home section links remain at the top of the page.
Plain anchors also force unnecessary document navigations.

**Approach:** Add a router-aware hash scroll component inside Suspense so it runs
after route content commits. On pathname/hash changes and browser history
navigation, wait until the target exists, then scroll it into view. Use React
Router `Link` for internal nav and project cards. Give all home anchor targets a
shared scroll margin that clears the fixed 80px navbar.
