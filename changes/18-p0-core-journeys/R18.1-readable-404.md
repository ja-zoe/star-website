# R18.1 — Readable 404

**Status:** tests passing
**Files:** `src/App.tsx`, `src/routes/NotFound.tsx`

## Spec

**Problem:** The app root inherits white text but not a dark background, so the
404 route renders white content over the body's light token background on cold
loads.

**Approach:** Make the global app shell a black, viewport-height surface and give
the 404 route an explicit black background, white text, and viewport minimum
height. Keep the global navbar/footer visible and the existing CTA intact.

## Tests

- [x] `pnpm build` passes.
- [x] Playwright cold-load desktop unknown route shows nav, 404 copy, CTA, and footer with black background.
- [x] Playwright cold-load mobile unknown route shows the same content without overflow.
