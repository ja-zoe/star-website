# R18.2 — Always-readable project cards

**Status:** done
**Files:** `src/components/ProjectCard.tsx`, `src/routes/home/ProjectsSection.tsx`

## Spec

**Problem:** Project cards show only an icon until hover, leaving touch and
keyboard users without visible project names or comparison information. Their
fixed 30rem height also dominates the mobile page.

**Approach:** Render every card's title, one-line purpose, three compact facts,
and "Explore project" affordance at rest. Use React Router links for internal
navigation. Reduce the mobile card height to the 220–280px audit target. Keep the
canvas reveal only as a lazy enhancement on hover-capable pointer devices, with
all core content above it and unchanged on hover/focus.

## Tests

- [x] `pnpm build` passes.
- [x] Playwright desktop shows all three titles, summaries, facts, and CTAs before hover and while focused.
- [x] Playwright mobile shows cards 220–280px tall with the same visible content and working links.
- [x] Touch-only emulation does not request the canvas reveal chunk before navigation.
