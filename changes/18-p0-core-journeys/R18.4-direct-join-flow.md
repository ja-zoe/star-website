# R18.4 — Direct join flow

**Status:** planned
**Files:** `src/routes/home/JoinUsSection.tsx`, `src/App.css`

## Spec

**Problem:** The primary recruiting CTA is a moving Discord target. This adds a
motor challenge, wastes mobile space, and gives no onboarding or non-Discord
path.

**Approach:** Replace it with a static high-contrast membership panel containing
three numbered steps: join Discord, choose a project/subteam, and attend a
meeting. Provide direct Discord and email CTAs, an honest Fall 2026
schedule-not-finalized state naming The Cage as the usual location, and concise
first-week expectations. Remove the obsolete movement CSS.

**Content constraint:** No authoritative meeting date/time/exact address exists
in the vault or repository. The fallback must not imply those details are known.

## Tests

- [ ] `pnpm build` passes.
- [ ] Playwright desktop and mobile show one obvious Discord CTA, email alternative, three steps, schedule state, and first-week guidance.
- [ ] Keyboard and reduced-motion users receive the same static join path.
- [ ] No moving-target CSS remains.
