## Notes / log
- 2026-10-05 - **Deviation: rectangular tiles, not set 17's circles.** Set 17 chose a red-400
  ringed circle so leadership would "look identical site-wide" to the e-board, which used
  circles at the time. The e-board has since become rectangular 4:5 WobbleCard portraits
  (design/components.md), so the rationale now points to rectangles. The e-board card was
  extracted into a shared `PersonTile` (home, leadership band, and R23.5's team page). Easy to
  revert to circles if the user prefers. Flagged at the merge checkpoint.
- 2026-10-05 - `PersonTile` takes `projectAccent` instead of relying on a CSS-variable fallback,
  because shadcn's theme defines `--accent` globally (`App.css`, a grey), so
  `var(--accent, red)` would have turned the home eyebrows grey.
- 2026-10-05 - Fixed name misalignment across a row when one role wraps and another does not
  (Robotics "Project Manager · Internal" needs 204 px of a 198 px line). This was also present
  on main's mobile home grid: Aayushi's name sat 12 px below Julian's. The role line now
  reserves two lines (`min-h-[2lh]`), and measured name offsets are equal within 1 px in every
  row on home mobile and the Robotics band.
- 2026-10-05 - Gate: lint 0 findings, build 0. A DOM check on all three pages matches the table
  above in order (names, role labels, photos vs placeholders), with section labels 01 to 06 and
  eyebrows in each project's accent (#F5A524 / #34D399 / #38BDF8); the home stays red-300. At
  1440x900 and 390x844: no overflow, broken images, failed requests, or console errors. Mobile
  CLS of 0.015-0.022 equals main exactly (3 runs each) and comes from the project hero, not this
  section. The prerender script only writes head/meta and share cards, so it needs no change.
