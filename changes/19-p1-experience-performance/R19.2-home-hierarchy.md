## Spec

**Problem:** The recruiting sequence hides the value proposition, delays project
choice behind a long About section, uses artificial 700px spacing, and relies on
decorative SVG text instead of semantic section headings. The mobile footer and
page length are disproportionate.

**Approach:** Make the visible hero `h1` "Build space systems at Rutgers," name
STAR and all three programs, and expose Join/Explore CTAs plus a current-status
strip. Reorder home to Hero → status → Projects → proof/About → Join → current
missions → FAQ → E-board → partners. Remove fixed spacer geometry, keep the
globe in a stable responsive frame, compact the mobile footer into one icon row,
and add real `h2` headings while marking SVG treatments decorative. Preserve
the deployed P0 card/join visual language and record the hierarchy convention.
