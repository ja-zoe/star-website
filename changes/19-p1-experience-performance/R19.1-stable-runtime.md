## Spec

**Problem:** A null route fallback lets the footer jump from the top of the
viewport when lazy routes resolve (audited CLS 0.518). Project waves and global
effects render continuously, including work that is invisible or unnecessary,
and the optional card reveal downloads an 846kB raw three.js chunk.

**Approach:** Reserve a viewport-height route surface with a stable dark
skeleton. Remove the card canvas reveal and replace it with the existing CSS
accent atmosphere. Keep one shooting-star layer. Rewrite the wave canvas with
typed refs and lifecycle controls: element-sized canvas, reduced DPR/density on
mobile, 30fps cap, pause offscreen/hidden, and one static frame for reduced
motion. Fix the globe's mutable render state with refs and responsive DPR/sample
settings. Remove the unused Inter request/style. Preserve the space identity.
