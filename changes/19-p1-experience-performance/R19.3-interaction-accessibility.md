# R19.3 — Interaction accessibility

**Status:** planned
**Files:** `src/routes/home/AboutStarSection.tsx`,
`src/components/HoverBlurCards.tsx`, `src/components/Navbar.tsx`,
`src/components/Footer.tsx`, `src/components/SubteamModal.tsx`,
`src/components/ui/sheet.tsx`

## Spec

**Problem:** The home page has a blank decorative focus stop, sponsor controls
nest links inside buttons, several touch targets are under 44px, the project
dialog close target is small, and the mobile navigation dialog lacks a title,
description, and expanded-state semantics.

**Approach:** Remove the decorative chevron link. Render each sponsor as one
tooltip-trigger anchor with safe new-tab attributes. Give social, hero, nav, and
dialog controls a 44px minimum target. Add a visually hidden SheetTitle and
SheetDescription; wire `aria-expanded`/`aria-controls` to the project submenu.
Keep focus order linear and visible, with no nested interactive elements.

## Tests

- [ ] `pnpm build` and touched-file ESLint pass.
- [ ] Playwright keyboard traversal finds no blank or duplicate focus stops.
- [ ] Mobile nav opens with no Radix accessibility warnings and reports the
      correct dialog name and project-toggle expanded state.
- [ ] Sponsor links are single controls with safe target attributes; important
      mobile targets measure at least 44×44px.
