# R21.1 — Not Found starfield

**Status:** in progress
**Files:** `src/routes/NotFound.tsx`

## Spec

**Problem:** The global `StarsBackground` and `ShootingStars` render on every route, but the Not Found
page's opaque black background covers them, making the 404 feel disconnected from the rest of STAR's
visual identity.

**Approach:** Remove only the Not Found page's opaque background utility so its existing elevated
content renders over the shared global atmosphere. Do not mount a second star canvas, change the
404 copy, or modify other routes. The existing global motion preference and visibility lifecycle
remain the single source of truth for the background animation.

- [ ] `pnpm lint` and `pnpm build` pass.

- [ ] The 404 has no horizontal overflow, console errors/warnings, or CLS regression.
